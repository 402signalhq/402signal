What the paid check adds

Your rules, the selected terms, and a receipt.

Your rules applied

Send a price ceiling, allowed networks, a latency bound or a required input schema and the check returns the option that meets them, or a typed reason nothing did.

Request fields

A signed receipt

Ask for require_route_binding and the answer binds the exact request and the seller's whole challenge. Verify it offline before your wallet signs.

What a receipt contains

Hooks that refuse

For supported profiles, a configured guard checks the current offer before the buyer signs. Confirm the request shape and hosted profile first; generic MPP observation does not itself provide a signed execution binding.

Add the hook

Alerts when it changes

With an admission key, subscribe a webhook to seller hosts. A signed event is delivered when a check observes a change. This does not schedule probes or provide continuous monitoring.
