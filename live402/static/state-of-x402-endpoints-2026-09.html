State of x402 endpoints.

What 22,072 paid API listings look like from the buyer's side: which rails they sell on, how many answer when asked, how long a challenge takes, and how often the terms change.

Generated from 402Signal's shadow catalog (CDP, PayAI and GoPlausible discovery feeds) and its own probe history for the 30 days ending 13 September 2026. Probes are triggered by buyer checks and readiness lookups, not uniform sampling, so rates are observed, not population estimates. Aggregates only; no buyer or payer identities. Regenerate with scripts/endpoint_report.py in the public repository.

Why probes missed: no 402 envelope 134, probe timeout 17, reachable with HTTP 200 and no challenge 10, upstream 5xx 7, blocked private address 2. The dominant miss is a listed URL that no longer answers with an x402 challenge at all.

Catalog claim events in the period: recipient changed 1, price changed 8, rail added 59, rail removed 9, resource added 48, schema changed 4,875. Schema changes dominate because sellers edit descriptions and input schemas far more often than prices or recipients.

What this says

  1. Roughly one listed URL in seven that 402Signal was asked about did not answer with a valid challenge. A catalog listing is not a live offer.
  2. Price and recipient changes are rare but real: 6 price changes and 1 recipient change among 316 tracked URLs in a month. Those are exactly the cases a pre-payment check exists for.
  3. Latency to a challenge is measured in seconds at p95 on every rail. Buyers that time out at one second will miss live sellers.
  4. Listing share, not chain count, should drive which networks a checker observes: Base, Solana, then the EVM chains.

Method

A listing is a resource advertised by a facilitator discovery feed. A probe is an unpaid HTTPS GET (with a narrowly justified empty POST fallback) from 402Signal to the listed URL; live means the seller answered with an x402 402 challenge; payable means the challenge carried a complete supported offer; invocable adds an input schema. Latency is round trip to the challenge from Fly.io in Ashburn. Recipient and price changes compare successive observations of the same URL. Sponsored and lab traffic classes are 402Signal's own tests and are excluded from the public numbers.

Sellers can check their own listing the way a buyer sees it, unpaid, at the readiness check. Buyers can search the catalog at Explore.
