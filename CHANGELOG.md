# Client releases

The current published JavaScript route guard is **0.7.7** and the Python client is **0.1.2**. Their published artifacts remain unchanged.

This repository contains the public clients, MCP adapter, integration contracts and verification code. The hosted service and website are maintained separately. Client source paths and local build helpers have been updated for this repository layout.

For historical package downloads and version-specific documentation, see [GitHub releases](https://github.com/402signalhq/402signal/releases) and [release verification](docs/releases.md). Historical tags preserve client package snapshots; they do not contain the full hosted-service source history.
